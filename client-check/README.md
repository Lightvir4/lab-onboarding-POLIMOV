# Диагностика клиентского компьютера

`pc_info.bat` собирает сведения об ОС, процессоре, памяти, диске C и установленных программах. Для корректной работы откройте файл двойным щелчком в Windows; сценарий формирует `pc_report.txt` рядом с собой.

Ветвь `feature/client-check` предназначена для ревью первой части задания. Расширенный аудит с рекомендациями подготовлен отдельно в ветви `feature/client-check-audit`.
