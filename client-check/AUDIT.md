# Аудит клиентского компьютера

Расширенная версия `pc_info.bat` не только собирает факты, но и:

- использует подпрограмму `:log` для единого вывода в окно и отчёт;
- очищает переменные перед сбором данных и продолжает работу при сбоях;
- проверяет наличие офисного пакета, браузера, PDF-просмотрщика, архиватора и антивируса;
- выделяет игровое ПО, торрент-клиенты, личные мессенджеры и развлекательные приложения для ручной проверки;
- удаляет временный список программ после завершения.

Рекомендации не являются командами на удаление: окончательное решение принимает администратор с учётом корпоративных задач и согласованных исключений.
