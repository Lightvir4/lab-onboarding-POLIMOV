# Quality Gate

Для лабораторной работы настроен отдельный workflow `QA Gate`. Он запускает `flake8` для каждого pull request в `develop`.

В истории ветки `feature/qa-gates` сохранены два учебных коммита: один с намеренными нарушениями линтера и второй с исправлением. Это фиксирует полный сценарий «сломать и починить».
