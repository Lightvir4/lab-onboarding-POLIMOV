# Практическое занятие 6

## Разрешение конфликта слияния

В `config.py` объединены изменения версии конфигурации и исправления безопасности:

```python
# Базовая конфигурация проекта. Версия 1.0. Исправлена ошибка безопасности.
```

Конфликт был вызван параллельным редактированием одной строки. При разрешении сохранены оба смысловых изменения, а конфликтные маркеры удалены.

## Трассируемость

Задача «Добавить логирование ошибок авторизации» связана с веткой `feature/logging`. Реализация находится в `logger.py` и предназначена для последующей интеграции с обработчиками авторизации.

## Контроль доступа

В `.github/CODEOWNERS` назначен владелец всех файлов и отдельно выделен `config.py`. Для ветки `develop` применяется процесс работы через pull request; это предотвращает неконтролируемые прямые изменения базовой линии.
