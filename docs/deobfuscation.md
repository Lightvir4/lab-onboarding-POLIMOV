# Деобфускация скрипта

Строка Base64 декодируется в:

```python
import os; os.system('rm -rf /')
```

Вызов `exec(b)` выполнил бы эту строку. На Unix-подобной системе команда пытается рекурсивно удалить содержимое файловой системы, что может привести к полной потере данных и неработоспособности системы.

## Защита

- не использовать `exec` для данных, полученных извне;
- проверять и разрешать только ожидаемые форматы входных данных;
- применять статический анализ для обнаружения `exec`, декодирования Base64 и опасных системных вызовов;
- запускать недоверенный код в изолированной среде с минимальными правами.
