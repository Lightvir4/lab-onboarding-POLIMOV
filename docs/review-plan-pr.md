# Изменения плана code review

Ветка `feature/review-plan` подготовлена для проверки плана ревью модуля скидок и шаблона pull request.

- актуальный план: [review-plan.md](review-plan.md);
- шаблон PR: [../.github/PULL_REQUEST_TEMPLATE.md](../.github/PULL_REQUEST_TEMPLATE.md);
- ключевые критерии: валидация, минимальная цена, покрытие тестами и эскалация споров.

Pull request по этой ветке оставляется открытым в соответствии с заданием.
