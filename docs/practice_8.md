# Практическая работа 8

## Диагностика клиентского компьютера

В каталоге `client-check/` находится пакетный сценарий `pc_info.bat`. Он формирует отчёт о системе, процессоре, памяти, диске C и установленных программах. Для получения данных используется PowerShell `Get-CimInstance` и реестр Windows: такой вариант работает в современных Windows, где `wmic` может отсутствовать.

## Выбранные категории базового ПО

Проверяются офисный пакет, браузер, PDF-просмотрщик, архиватор и антивирус. Это минимальный набор для работы с документами, веб-сервисами, вложениями и безопасностью рабочего места.

## Признаки ПО для проверки

Игровые платформы, торрент-клиенты, личные мессенджеры и развлекательные приложения отмечаются как требующие проверки. Сценарий не удаляет программы: итоговое решение принимает администратор с учётом корпоративного стандарта.

## Проверка логики и ограничения

Проверены обе ветви логики: обнаружение отсутствующей категории и обнаружение контрольного названия из списка нежелательного ПО. Сценарий анализирует зарегистрированные приложения, поэтому portable-программы без записи в реестре могут не попасть в отчёт.
