# Инфраструктура репозитория

В ветке `feature/infrastructure` зафиксирована базовая инфраструктура проекта:

- `.editorconfig` задаёт UTF-8, отступы 4 пробела и LF;
- `.github/CODEOWNERS` назначает владельца репозитория;
- `develop` используется как интеграционная ветка;
- feature-ветки изолируют учебные изменения до ревью.

Эта ветка предназначена для pull request в `develop` и после проверки может быть объединена.
