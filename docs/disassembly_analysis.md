# Дизассемблирование фрагмента x86-64

`-4(%rbp)` используется как аккумулятор `total`, а `-8(%rbp)` - как счётчик `i`. Инструкция `jle .L3` возвращает выполнение в тело цикла, пока `i <= 10`.

Эквивалент на Python:

```python
total = 0
i = 1
while i <= 10:
    total += i
    i += 1
return total
```

Фрагмент вычисляет сумму чисел от 1 до 10 включительно. Результат равен `55`.
